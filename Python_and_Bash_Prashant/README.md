# Python & Bash - DevOps Assignment

This project contains the Python tasks shown in the assignment:

- Grade Checker using `if / elif / else`
- Student Grades using a dictionary, add/update/print, and `if / else`
- Writing data to a text file using `open()` and `write()`
- Reading data from a text file using `file.read()`

## Project structure

```text
Python_and_Bash_Prashant/
├── project/
│   ├── grade_checker.py
│   ├── student_grades.py
│   ├── write_file.py
│   └── read_file.py
├── scripts/
│   └── run_project.sh
├── screenshots/
├── commands.txt
├── Python_and_Bash_Documentation.docx
└── README.md
```

## How to run

```bash
cd project
python3 grade_checker.py
python3 student_grades.py
python3 write_file.py
python3 read_file.py
```

Or run all tasks with the Bash helper script:

```bash
./scripts/run_project.sh
```
