# Linux Basics – DevOps Assignment

This project covers the 12 Linux tasks provided in the assignment:
file/directory creation, rename, file viewing, grep search, zip/unzip, wget download,
chmod permissions, and environment variables.

## How to use

1. Open Ubuntu/Linux terminal.
2. Run the commands in `commands.txt` one by one.
3. Take a screenshot after each task showing the command and output.
4. Put the screenshots in the `screenshots/` folder.
5. Update `Linux_Basics_Documentation.docx` with the screenshots and your GitHub URL.
6. Push the project to GitHub.
7. Compress this complete folder as `Linux_Basics_Prashant.zip`.

IMPORTANT: Screenshots must be genuine terminal screenshots from your own execution.
Do not submit placeholder screenshots.
